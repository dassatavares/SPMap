# SPMap

Mapa interativo dos municípios do estado de São Paulo. Pesquise uma cidade para localizá-la e destacá-la no mapa.

## Requisitos

- Node.js 20.19+ ou 22.12+
- npm

## Desenvolvimento

```sh
npm install
npm run dev
```

## Verificação e build

```sh
npm run lint
npm run build
```

O build de produção é gerado na pasta `dist/`.
